Dependencias: [`odoo-tmc`](https://github.com/tmcrosario/odoo-tmc), [`odoo-partner`](https://github.com/tmcrosario/odoo-partner).

Agregar a la ruta de addons, actualizar aplicaciones e instalar «TMC Auditors».
